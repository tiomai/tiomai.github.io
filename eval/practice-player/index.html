STRAIGHT LINES

Line L₁ has equation 2x − 3y + 5 = 0. Line L₂ is perpendicular to L₁ and has x-intercept 4. Which equation represents L₂?

MULTIPLE CHOICE

Choose the best answer.

Correct

Why: L₁ has slope ⅔, so a perpendicular line has slope −³⁄₂. Using the x-intercept (4, 0) gives y = −³⁄₂x + 6.

Study tip: Perpendicular slopes multiply to −1.
