KOKOMONSTER / ARCHIVE

The reference collection

Original extractions, turntable frames and early explorations, preserved for reference.

Guidelines · README
  • extracted-library/characters/: original JP108 and selected 365 transparent layer extractions.
  • extracted-library/drive-thumbnails/: source shortlist thumbnails.
  • extracted-library/scenes/ and sources/: historical scene previews and source comparisons; thumbnails are not production-resolution scenes.
  • extracted-library/*manifest.json and layered-source-inventory.json: extraction and source provenance.
  • exploration/: frame extractions, audit boards, source audits, historical styles and generation trials.
  • legacy-character-visual-guide.md: historical identity guide; current corrections override it.

Archived here as training/reference material at the user's request. This is a storage classification; no model training has been performed. Stable original IDs are preserved. Existing theme copies remain in place for runtime compatibility.
