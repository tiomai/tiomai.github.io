# Game illustration style trials — 12 September 2026

Status: exploratory mockups for choosing a finish, not approved production artwork. Generated using the built-in image-generation tool. Exact prompts are in prompts.json. The user-supplied game-character sheet provides drawing-language inspiration only; verified rotation and authored editorial boards provide Kokomonster identity references.

## Criteria for current use

| Criterion | Review test |
| --- | --- |
| Identity | Recognize all six by silhouette, signature marks and colour; compare face, tail, costume and asymmetric details against rotation references. |
| Small-size clarity | Test each isolated character at 64, 96 and 160 CSS pixels. Simplify detail before enlarging artwork at the expense of reading space. These sizes are proposed trials, not validated thresholds. |
| Landing-page hierarchy | Illustration supports the Japanese reading experience; face, props and accents leave headline, Japanese copy and CTA areas clear. |
| Expression and activity | Pose communicates reading, exploring or practicing before supporting copy is read. Props have plausible contact with hands. |
| World consistency | Characters, props and backgrounds share contour weight, shape language, palette, perspective and shadow treatment. |
| Reuse | Character, held prop, environment and foreground remain separable in production. Recompose for wide, square and portrait layouts rather than cropping a single flattened scene. |
| Motion readiness | Define resting pose, expressions, joints and prop anchors after selecting the finish; provide a static equivalent for every animation. |

## Three directions

- A, Flat Adventure: broad colour shapes and selective internal lines, closest to the supplied reference. Lead candidate for character-and-world illustrations.
- B, Bold Sticker: stronger dark contours and compact shapes. Candidate for small product moments, learning rewards and game UI; readability still needs target-size testing.
- C, Soft Story Game: gentle colour and restrained grain. Candidate for reading scenes and warm editorial storytelling.

Every board compares the six characters without activity props and with the same activity assignment: Koko/book; Gohanko/tea; Bear/pencil and notebook; Rabbit/map; Yauyau/magnifier and leaf; Tree/watering can and sprout. Rabbit's pink paws and red scarf are an exploration choice; boxing gloves remain a sport costume option. Character scale on the sheets is for comparison, not a canonical height chart.

## Recommended system after selection

Freeze one construction sheet per character (front, three-quarter, side, back), one approved palette and one main rendering finish. Create a shared prop library with grip/contact anchors. Build scenes from ground, distant setting, props, character, foreground accents and separate live text. Use simpler, lower-contrast backgrounds so faces and reading content retain priority. Reuse the same tree, furniture, foliage and architectural shape vocabulary across scenes.

Next validation should be one reading vignette rendered in the selected finish in a wide landing-page slot, a square card and a portrait composition. Only then expand pose count. Production delivery should include editable layered masters, isolated transparent exports, size-specific simplifications and separately prepared motion assets. These generated PNG boards are concept references and are not editable vectors or Lottie animations.
