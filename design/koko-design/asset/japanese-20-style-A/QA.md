# Scene review — Style A

Twenty individual landscape illustrations were generated and visually inspected. This is a scene mockup collection for page composition, not a new canonical character model sheet.

## Identity review

- Gohanko's accessory is a fish-shaped shoyu bottle. The generation briefs specify its fins, tail, red mouth cap and soy fill. Bottle scale, orientation and detailing vary between scenes; use one approved bottle drawing for final vector masters.
- Tree's nose remains visible and uses the rounded terracotta shape. Small width and shading differences remain across the generated scenes. Seven scenes received targeted corrections to restore green hands after costumes introduced peach hands.
- Koko, Gohanko and Rabbit retain visible noses. Yauyau is shown with two scarf arms.
- Costumes preserve the main silhouettes and face markings. Bear's brow expression varies, particularly in riverside reading. These expressive differences should be resolved against the master sheet when preparing final editable art.

## Composition and delivery

- Each PNG has a landscape composition with space for separately rendered page copy. Mobile layouts should stack copy above the image and preserve the full character group.
- Scenes are stylised settings, not depictions of a specific real Japanese location. Some contain decorative landmarks beyond the primary activity brief.
- The winter kotatsu scene includes a background sleeping cat, not an additional Kokomonster cast member.
- Page placements in README.md are proposals. No live site was changed and actual page crops have not been tested.
- PNG files are flattened. Layer separation, animation rigs, responsive image exports and final vector identity cleanup are outside this mockup delivery.

The manifest records source files, prompts, dimensions and hashes. Corrections are recorded separately in corrections.json; original generated outputs remain preserved.
