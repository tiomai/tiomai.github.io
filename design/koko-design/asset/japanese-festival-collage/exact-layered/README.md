# Exact layered version

This master is built directly from the supplied 1254 × 1254 artwork. It does not regenerate or redraw the visible composition.

Open `KM-CAM-A-japanese-festival-exact-layered.svg` in Figma, Illustrator, Affinity Designer or Inkscape. The fidelity underlay is hidden by default so the editable title and lantern label layers are visible without duplicate artwork. Turn on **00 Exact fidelity underlay — hidden for editable title and lantern labels** only for source comparison.

Named layers separate the main items: background and loose accents, Mount Fuji and sun, fan, two lanterns, editable やさしい日本語 title artwork, two blank lantern labels, six characters with their props, wave motif and supplied logo artwork. A hidden locked reference layer allows direct comparison. The title text reads やさしい日本語 and is live SVG text; each lantern label is an independent blank layer. The verified official logo remains available as a hidden replacement.

Because the supplied source is a flattened bitmap, exact-looking layers remain raster fragments with editable SVG masks and transforms. They can be selected, moved, resized, hidden and replaced independently. Individual brush shapes inside a character cannot become true vector paths without manually redrawing them, which would no longer be pixel-identical. The fidelity underlay should stay visible only for comparison or unchanged export; otherwise it would reveal duplicates when a clipped item moves.

Keep the SVG beside its `layers/` folder. Edit the live title text layer directly when copy must change; keep each item group independently selectable.
