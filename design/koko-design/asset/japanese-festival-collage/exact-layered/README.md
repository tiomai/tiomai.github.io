# Exact layered version

This master is built directly from the supplied 1254 × 1254 artwork. It does not regenerate or redraw the visible composition.

Open `KM-CAM-A-japanese-festival-exact-layered.svg` in Figma, Illustrator, Affinity Designer or Inkscape. The default view includes an exact fidelity underlay, so it is identical to the supplied source. Hide the layer named **00 Exact fidelity underlay — hide before rearranging** when adapting the composition; the independently selectable clipped layers remain visible for editing.

Named layers separate the main items: background and loose accents, Mount Fuji and sun, fan, two lanterns, exact title artwork, six characters with their props, wave motif and supplied logo artwork. A hidden locked reference layer allows direct comparison. Hidden alternatives provide live Japanese title text and the verified official logo.

Because the supplied source is a flattened bitmap, exact-looking layers remain raster fragments with editable SVG masks and transforms. They can be selected, moved, resized, hidden and replaced independently. Individual brush shapes inside a character cannot become true vector paths without manually redrawing them, which would no longer be pixel-identical. The fidelity underlay should stay visible only for comparison or unchanged export; otherwise it would reveal duplicates when a clipped item moves.

Keep the SVG beside its `layers/` folder. Use the original exact title layer for visual fidelity; use the hidden live-title alternative when copy must change.
