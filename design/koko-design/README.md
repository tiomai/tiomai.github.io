# Kokomonster design library

- [UI design guideline](UI-GUIDELINES.md): interface colours, typography, layout and component usage.
- [Character library](character/README.md): character assets, rotation sources, current styles and identity rules.
- [Scene assets](asset/README.md): current page illustrations and comparison boards.
- [Archive](archive/README.md): extracted reference material, source records and historical trials.

Style A — Flat Adventure is selected for the landing page. Gohanko carries a fish-shaped shoyu bottle. Generated scenes remain mockups with review notes, rather than canonical character masters.

This is the central local library. Existing theme runtime assets are retained to preserve page paths; their reference copies live in the archive. Old exploration file paths remain as compatibility links. migration-manifest.json records every relocated or copied file and its original hash.
